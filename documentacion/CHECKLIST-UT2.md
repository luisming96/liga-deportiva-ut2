# Checklist - Proyecto Entregable UT2

## Repositorio y preparación

- [ ] Crear un repositorio privado en GitHub.
- [ ] Trabajar con commits durante el desarrollo.
- [ ] Crear el proyecto Angular desde la terminal.
- [ ] Mantener el proyecto original de la U1 como referencia.

## Parte I - Estructura del proyecto (20 %)

- [ ] Crear la estructura Angular del proyecto.
- [ ] Agrupar los componentes en sus carpetas correspondientes.
- [ ] Preparar los servicios y módulos para la parte servidora.
- [ ] Crear el header.
- [ ] Crear el footer.
- [ ] Crear el componente de noticias.
- [ ] Crear el componente de equipos.
- [ ] Crear el componente de jugadores.
- [ ] Crear el componente de clasificaciones.
- [ ] Crear el componente de árbitros.
- [ ] Adaptar el código de la U1 a componentes Angular.
- [ ] Comprobar que la página es responsive, al menos en móvil.

## Parte II - Componentes y base de datos (80 %)

### Usuarios y roles

- [ ] Crear el componente de inicio de sesión.
- [ ] Incluir los campos de usuario y contraseña.
- [ ] Crear el componente de registro.
- [ ] Crear el clúster gratuito de MongoDB Cloud.
- [ ] Crear la base de datos `LigaDeportiva`.
- [ ] Crear la colección `usuarios`.
- [ ] Crear el servicio de acceso a MongoDB.
- [ ] Hacer el registro mediante una petición POST.
- [ ] Hacer el login mediante una petición GET.
- [ ] Añadir la variable `tipo` al documento de usuario.
- [ ] Redirigir según el tipo de usuario:
  - [ ] Usuario normal.
  - [ ] Administrador.
  - [ ] Capitán.
  - [ ] Árbitro.

### Funcionalidad mínima por rol

- [ ] El administrador puede crear un partido.
- [ ] El administrador puede seleccionar dos equipos.
- [ ] El administrador puede indicar el deporte.
- [ ] El administrador puede asociar un árbitro.
- [ ] El administrador puede modificar el resultado.
- [ ] El administrador puede modificar la fecha.
- [ ] El administrador puede modificar el árbitro.
- [ ] El administrador puede modificar la ubicación.
- [ ] El árbitro ve solamente los partidos que debe arbitrar.
- [ ] El usuario ve solamente los partidos de su equipo.
- [ ] Cada página tiene varios componentes con alguna funcionalidad.
