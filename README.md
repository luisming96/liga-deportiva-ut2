# Liga Deportiva del Instituto - Proyecto UT2

Proyecto Angular para la segunda unidad de Framework.

La aplicación adapta el proyecto realizado en la Unidad 1 y lo convierte en una
estructura por componentes.

## Contenido del proyecto

- Página de inicio.
- Equipos.
- Jugadores.
- Clasificaciones.
- Árbitros.
- Resultados.
- Inicio de sesión y registro.
- Conexión con MongoDB.
- Diferentes tipos de usuario.

## Ejecución del frontend

```powershell
cd liga-deportiva-ut2-app
npm install
npm start
```

La aplicación estará disponible en `http://localhost:4200`.
